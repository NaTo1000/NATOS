⚡ UNDERSTANDING THE NUMBERS

RPM (Revolutions Per Minute):
  Idle: 800-900
  Normal: 2000-4000
  Performance: 4000-6500
  Redline: 7000-7800 (depends on mode)

Boost Pressure (PSI):
  Off-throttle: 0 PSI
  Part throttle: 3-8 PSI
  Full throttle: 12-22 PSI (mode dependent)

AFR (Air/Fuel Ratio):
  Stoichiometric: 14.7:1 (perfect combustion)
  Economy: 15.0-15.5:1 (lean)
  Normal: 13.5-14.5:1
  Power: 11.5-12.5:1 (rich)
  ⚠️ Dangerous: <11.0 or >15.0 under boost

Temperatures:
  Coolant: 180-210°F normal, >220°F warning
  Oil: 180-240°F normal, >260°F warning
  Exhaust: 800-1400°F normal, >1600°F critical

🔧 TROUBLESHOOTING

Server won't start?
  → pip install -r requirements.txt
  → Check if port 5000 is available

Dashboard not loading?
  → Try http://127.0.0.1:5000
  → Check browser console for errors
  → Ensure JavaScript is enabled

Charts not updating?
  → Refresh browser (Ctrl+F5)
  → Check if engine is started
  → Look for WebSocket errors in console
